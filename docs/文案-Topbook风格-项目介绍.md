# 千语鸟热点看板 · Qianyuniao Trending Topics

每天想搞清楚今天世界上发生了啥，我基本得在微博、抖音、B 站、朋友圈之间来回切。半小时下去，能记住的没几条。

所以这阵子我自己搭了个看板，把这些信息源都摊到一个能拖来拖去的地方。叫千语鸟热点看板，现在跑在线上，免费开源，你直接打开就能看：

🔗 https://qianyuniao.pages.dev/pages/trendingtopics/

它现在接了 55 个热榜平台的适配器，199 个内容源。热榜、短视频、最热、实时这几个是基础；另外还有两块比较硬核的：一块是顶刊论文广场，Nature、Science、Cell 系加上 JAMA、Lancet、bioRxiv；一块是政策广场，国务院加 52 个部委的官网公文和解读。再叠一个统计数据看板，把统计局、央行、财政部和另外 38 个权威统计平台的入口都摞在上面。说白了就是想在一个地方看全，不用开八个 App 去拼一张世界地图。

卡片能拖。你关心啥就拖到最前，不关心的往后挪。任意一张卡片可以"加入关注"，用 GitHub 登一下，关注的栏目就能跨设备同步，公司看一半回家手机接着看。

它是个 PWA，Service Worker 把内容预缓存了，没网的时候之前加载过的也能翻，还能装成桌面和手机上的 App。

加新源不算麻烦。数据源是声明式的：在 pre-sources.ts 里写一行声明，再去 server/sources/ 放个抓取文件，基本就成了。要多接一个政府部门，数组里加一项就行。政府网站那些破事它替你处理：GBK、GB18030 这种老字符集兜底解码，碰到反爬挑战页就进沙箱把 Cookie 解出来再试，列表容器自动选最深的那个，避开导航和页脚的噪音。

代码开源，MIT。能自己部署到 Node、Cloudflare Pages、Vercel、Bun。数据在你自己手里，平台哪天不爽关你账号，这边不受影响。懒得搭就直接用线上那个。

我是千语，这个看板就是我自己搭的，现在已经上线、免费开源。去 qianyuniao.pages.dev/pages/trendingtopics/ 逛逛，有想法随时找我。
