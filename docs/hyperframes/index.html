每天想搞清楚今天世界上发生了啥，我基本得在微博、抖音、B 站、朋友圈之间来回切。半小时下去，能记住的没几条。
所以这阵子我自己搭了个看板，把这些信息源都摊到一个能拖来拖去的地方。叫千语鸟热点看板，现在跑在 qianyuniao.pages.dev/pages/trendingtopics/ ，免费开源，你直接打开就能看。
它现在接了 55 个热榜平台的适配器，199 个内容源。新闻、财经、社交、短视频、学术、政务，一个地方看全。
还有两块比较硬核的：顶刊论文广场，Nature、Science、Cell 系加上 JAMA、Lancet、bioRxiv；政策广场，国务院加 52 个部委公文解读；再叠一个统计数据看板，统计局、央行、财政部和 38 个权威平台入口都摞在上面。
卡片能拖。你关心啥就拖到最前，不关心的往后挪。任意一张能加入关注，GitHub 登一下，关注的栏目跨设备同步，公司看一半回家手机接着看。
它是个 PWA，Service Worker 把内容预缓存了，没网的时候之前加载过的也能翻，还能装成桌面和手机上的 App。
加新源不算麻烦。数据源是声明式的，pre-sources.ts 写一行声明，server/sources/ 放个抓取文件，基本就成了。多接一个政府部门，数组里加一项。
政府网站那些破事它替你处理：GBK、GB18030 这种老字符集兜底解码，碰到反爬挑战页就进沙箱把 Cookie 解出来再试，列表容器自动选最深的那个，避开导航和页脚的噪音。
代码开源，MIT。能自己部署到 Node、Cloudflare Pages、Vercel、Bun。数据在你自己手里，平台关你账号这边不受影响；懒得搭就直接用线上那个。
比起那些臃肿的资讯聚合站，它没多余功能，本地跑、自己管数据，个人也能很快搭起来。
